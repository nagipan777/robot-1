# P3–P7 completion status — 2026-10-27

## P3: Cause-based ARM/TCP repair

Completed in host code and tests.

- Confirmed one defect common to ARM ACK and READY recovery: non-blocking Pico
  `send()` returning `None` was counted as a complete write.
- `send_all()` now retries temporary no-progress results, handles partial writes,
  returns the real byte count, and fails within the existing 100 ms deadline.
- ARM is connection-scoped and transitions through `ARM_PENDING`; commit requires
  the same state, generation, connection ID, and a reservation age below the
  unchanged 500 ms limit.
- STOP, timeout, send failure, commit failure, or TCP close clears authorization
  and latches STOP. A later/old ACK cannot restore `ARMED`.
- READY clients that send no first frame are released after 500 ms so the
  single-client server can accept the next connection.

Real-Pico confirmation remains pending; therefore the incident is classified as
partially improved rather than fully resolved.
